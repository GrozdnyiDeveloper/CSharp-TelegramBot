# Telegram бот на C#
В данном репозитории представлена реализация чат бота для Telegram по поиску данных компаний по ИНН, тесты для проверки работы его функций и файл настроек для контейнеризации бота в Docker. 

**Телеграмм бот имеет следующий набор команд:**
- /start – начать общение с ботом
- /help – вывести справку о доступных командах
- /hello – вывести ваше имя и фамилию, ваш email и ссылку на github
- /inn – получить наименования и адреса компаний по ИНН
- /last – повторить последнее действие бота
- /okved - получить коды (ОКВЭД) и виды деятельности компании по ИНН

**Архив имеет следующее содержимое:**
- TelegramBot - Проект, содержащий простого чат бота для Telegram по поиску данных компаний (наименования, адреса, коды ОКВЭД и виды деятельности) по их ИНН написанного на C#
- TelegramBot.Test - Проект, содержащий в себе Unit тесты на C# для проверки корректности работы бота из проекта TelegramBot
- Dockerfile - Образ для контейнеризации в Docker чат бота из проекта TelegramBot.
